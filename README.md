# 📚 VocabMaster: Samundramanthan 200 Vocabulary Hub

An interactive, high-retention English & Hindi vocabulary learning web application based on the complete 22 pages of **"Samundramanthan of Vocabulary" (English With Rani Ma'am)**.

---

## 🌟 Key Features

1. **📚 Complete 200-Word Database with Dual Hindi Meanings**:
   - Every word (1 to 200) contains parts of speech, Hindi meanings for synonyms, all synonyms, Hindi meanings for antonyms, all antonyms, and contextual examples.
   - Over **2,140+ synonyms** and **1,570+ antonyms** cross-referenced.

2. **🔍 Interactive Study Hub**:
   - Instant live search by English word, Hindi meaning, synonym, or antonym.
   - Filters by Set (1-50, 51-100, 101-150, 151-200), Part of Speech (Noun, Verb, Adjective, Adverb), and Mastery Status.
   - Clickable synonym and antonym tag pills.
   - Text-To-Speech (TTS) English audio pronunciation.
   - Grid Card view and Fast Table view.

3. **🗂️ 3D Interactive Flashcards**:
   - 3D flip card animations with English $\leftrightarrow$ Hindi flip modes.
   - Spaced repetition rating buttons (Easy / Mastered, Review, Hard).
   - Keyboard shortcuts: `Space` to Flip, `←` / `→` for Navigation, `1`, `2`, `3` for Rating.

4. **📝 Mock Test Arena**:
   - Multiple exam formats: **Synonym MCQ**, **Antonym MCQ**, **English $\rightarrow$ Hindi**, **Hindi $\rightarrow$ English**, and **Mixed Exam**.
   - Timed countdown tests (30s / 20s per question) with instant explanation boxes.
   - Score reports with accuracy %, performance breakdown, and **"Retest Missed Questions Only"** feature.

5. **🎮 Retention Mini-Games**:
   - **Memory Tile Match**: 12-tile interactive memory game to pair English words with Hindi meanings.

6. **📊 Daily Productivity & Progress Tracking**:
   - Daily streaks counter (🔥).
   - Mastered vs In-Learning vs Starred tracker saved automatically in `localStorage`.
   - Starred / Bookmarked words hub with one-click printable cheat-sheet.

---

## 🚀 How to Run the App

### Method 1: Direct Browser Open (No installation needed)
Simply double-click or open `index.html` in Google Chrome, Microsoft Edge, Brave, or Firefox.

### Method 2: Local Python Server
Run the included python server script in your terminal:
```bash
python serve.py
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.
